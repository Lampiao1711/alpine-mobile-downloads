# Alpine Mobile Downloads

Página pública e manifestos do launcher Alpine Roleplay para Android. A página é servida pelo GitHub Pages; o APK e os arquivos do cache são distribuídos como assets do GitHub Release `v1.0.52`.

O cache é publicado em arquivos separados para manter compatibilidade com o atualizador do launcher. A pasta `_backups` e APKs antigos não fazem parte da distribuição.
